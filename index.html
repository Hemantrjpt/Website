Briefing

Common questions before deployment.

Are these scripts free?

Yes — every script in the archive is free to use. Joining the Discord helps support ongoing development, but it's never required.

Will using a script get my account banned?

Any third-party script carries some risk. Use your own judgment, and consider testing on an account you're not attached to before running anything on a main.

How do I install a script?

Open a script's page, copy it, paste it into your executor, and run it. Each script page has the exact steps.

Can I request a script for a specific game?

Drop a request in the Discord. New scripts get prioritized based on community interest.

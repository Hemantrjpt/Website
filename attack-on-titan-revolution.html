Overview

A full automation suite for Attack on Titan: Revolution, covering everything from early-game farming to end-game prestige resets. It's been rebuilt across every major patch to keep pace with the game's remotes.

What it does

  • Auto-farm routines tuned per map
  • Combat automation for wave and boss fights
  • Forest quest automation
  • Auto-upgrades and prestige handling
  • Family roll automation
  • Webhook notifications for key events
  • Obsidian-based UI
Requirements: any Roblox executor that supports HTTP requests via loadstring. See supported executors

Get script

loadstring(game:HttpGet("https://raw.githubusercontent.com/yourusername/titanic-hub/main/loader.lua"))()
  1. Copy the script above.
  2. Open your executor.
  3. Paste the script and execute.
  4. The Titanic Hub UI opens in-game.
